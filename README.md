# javascript quiz application
JavaScript Animated Quiz App 

This repository contains a fully responsive and interactive JavaScript Quiz Web Application built using plain HTML, CSS, and JavaScript. The application presents users with multiple-choice questions and challenges them to answer each question within a fixed time limit of 20 seconds. It is designed as a beginner-friendly but professional-level project that demonstrates how front-end technologies work together to create dynamic, real-time user experiences without relying on external libraries or frameworks.

The project focuses on clean design, smooth animations, timer-based logic, real-time score tracking, and user feedback. It is ideal for anyone looking to understand how JavaScript controls user interactions, animations, and application logic directly in the browser.

## Overview of the project

This quiz application displays a series of JavaScript-related multiple-choice questions. Each question contains four options, out of which only one is correct. When a user selects an option, the app instantly highlights the correct answer and visually indicates whether the selected answer is right or wrong by applying different colors.

A 20-second countdown timer is active for every question. If the user does not answer in time, the app automatically disables all answers, highlights the correct one, and enables the "Next" button. This increases engagement and simulates real-test pressure.

At the end of the quiz, the application displays a result screen showing the total score out of the total number of questions. The quiz can be restarted anytime using the restart button without refreshing the page.

The application is modularized in three main files:

- index.html – contains the quiz layout and structure.

- style.css - controls design, animations, responsiveness, and colors.

- script.js – Controls logic, timing, loading questions, scoring, and user interaction.

- How It Works

Questions are stored in an array of JavaScript objects inside script.js. Each object contains:

The question text

Four possible answers

Correct answer key

- When the quiz loads:

The current question loads dynamically.

A 20-second timer starts.

The progress bar starts shrinking.

When the user selects an answer:

Timer off

Correct and wrong answers are highlighted

Score updates if correct

- When the timer reaches zero:

Correct answer is shown automatically

Question Locks

User can move forward

The "Next" button advances through questions. When all questions are completed, the quiz card is replaced with a results card showing the final score.
